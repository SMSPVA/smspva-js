# Changelog

## 0.1.0-alpha.1

- Add asynchronous JavaScript and TypeScript clients for all 56 documented Activation V2, Rental and Private Email operations.
- Support ESM and CommonJS with TypeScript declarations.
- Preserve documented HTTP methods, parameters, response fields, pending SMS and no-stock results.
- Include cancellation, timeouts and an SMS polling helper with a saved expiry.
- Add MIT licensing and local contract tests. Alternative API is excluded.

This alpha has not been validated against paid production operations.
